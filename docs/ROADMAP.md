# Roadmap

High-level vision for afterglow-engine. This is a living document — vague plans, hopes, and dreams.

## Near-term

- [ ] Core ECS scaffolding and plugin architecture
- [ ] Basic player controller (first-person or third-person)
- [ ] Scene loading (glTF / ron)
- [ ] Physics integration (rapier or bevy_xpbd)

## Mid-term

- [ ] Animation system (blend trees, state machines)
- [ ] Audio system (spatial audio, streaming)
- [ ] UI/HUD framework (contribute to bevy_ui or custom)
- [ ] Save/load game state
- [ ] Input rebinding and controller support

## Long-term

- [ ] Multiplayer / netcode (client-server or P2P)
- [ ] Editor / tooling (in-game or standalone)
- [ ] World streaming / chunking for large scenes
- [ ] Modding support (scripting, asset override)
- [ ] Polish pipeline (post-processing, LOD, streaming)

## Milestones

| Milestone | Target | Description |
|-----------|--------|-------------|
| v0.1.0    | TBD    | Playable prototype with basic 3D scene, player controller, physics |
| v0.2.0    | TBD    | Animation + audio + UI |
| v0.3.0    | TBD    | Save/load + input rebinding |
| v1.0.0    | TBD    | Feature-complete for shipping a small game |
